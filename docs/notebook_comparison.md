# Выбор основного ноутбука

Основным выбран `full-final.ipynb`, опубликованный в корне как [final_solution.ipynb](../final_solution.ipynb). Его содержимое и сохранённые выводы перенесены без изменений.

| Показатель | blending-trials | full-final |
| --- | ---: | ---: |
| Кодовые ячейки, включая пустые | 36 | 59 |
| Markdown-ячейки | 29 | 45 |
| Строки исходного Python-кода | 4,160 | 13,575 |
| Уникальные имена функций и классов | 83 | 167 |

Все 83 имена функций и классов из `blending-trials` присутствуют в `full-final`. При этом реализации и конфигурация развивались: в полном ноутбуке базовая активная часть использует четыре CatBoost/XGBoost-модели, а LightGBM отключён.

В `full-final` дополнительно есть:

- stochastic/column bagging, weighted specialists и Ridge;
- иерархический блендинг и affine-калибровка;
- calibrated hurdle-ансамбль с моделями вероятности и условной величины покупки;
- Error Analysis v2;
- отдельный блок adaptive-моделей, отключённый по умолчанию;
- дополнительные варианты итоговых смесей, включая внешние прогнозы коллег.

Выбор сделан по полноте представленного pipeline. Ноутбук содержит несколько кандидатов submission; точный файл, использованный для финального результата соревнования, отдельно не указан. Для внешних смесей требуются дополнительные CSV, отсутствующие в переданных материалах.

`blending-trials.ipynb` оставлен исходным материалом сравнения и отдельно в репозиторий не дублируется.
